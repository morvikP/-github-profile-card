# GitHub Profile Card

Веб-приложение для просмотра информации о GitHub-пользователях. Вводишь юзернейм — получаешь карточку с профилем и списком последних репозиториев.

## Функционал

- Поиск GitHub-пользователей по юзернейму
- Отображение карточки профиля: аватар, имя, био, статистика
- Список последних 5 репозиториев с описанием
- Обработка ошибок (пользователь не найден, проблемы с сетью)
- Индикатор загрузки
- Адаптивный дизайн

## Технологии

- HTML5
- CSS3 (без фреймворков)
- JavaScript (чистый, без библиотек)
- GitHub REST API (без авторизации)

## Как использовать

1. Введите GitHub-юзернейм в поле поиска
2. Нажмите «Найти» или клавишу Enter
3. Просмотрите карточку профиля и список репозиториев

## Локальный запуск

Просто откройте `index.html` в браузере. Никаких дополнительных зависимостей не требуется.

## Примечание

GitHub API без авторизации имеет лимит 60 запросов в час с одного IP-адреса. При превышении лимита API возвращает ошибку 403.
